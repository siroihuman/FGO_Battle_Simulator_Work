# No.059 那須与一 実装前提 共通条件検査

日付: 2026-08-25
仕様書バージョン: 1.0.0
PR: #80

## 対象

No.059「那須与一」の強化後宝具と絆礼装で必要になる、「攻撃対象が回避または無敵状態の時だけ有効になる攻撃補正」の共通条件を検査する。

那須与一本体と絆礼装は本検査の対象外とする。参照Wikiで絆礼装の名称が欠落しているため、既存規則どおり名称を推測せず、ユーザー確認まで登録を停止する。

## 実装

- `AppliedEffect.flags.requiredTargetEvadeOrInvincibility = true`を既存の攻撃元補正照合へ接続した。
- 対象に`evade`または`invincibility`が1件以上存在する時だけ補正を有効にする。
- 回避と無敵の両方が同時に存在しても同じ攻撃元効果を二重加算しない。
- `solemn_defense`だけでは条件を成立させない。
- 必中・無敵貫通は対象状態の存在条件を消さない。
- 条件照合で状態・効果採番・乱数を変更しない。
- BattleSession、中断保存形式4、データ1.38.0、行動ログ形式5、ターンログ形式2、カード再配布、6乱数列を変更しない。

## 回帰検査

`tests/attack-input.test.ts`へ以下を追加した。

1. 回避・無敵なし: 条件付き補正0。
2. 回避のみ: 条件付き補正が有効。
3. 無敵のみ: 条件付き補正が有効。
4. 回避＋無敵: 1回分だけ有効。
5. 対粛正防御のみ: 条件付き補正0。
6. 通常クリティカル: 条件付きクリティカル威力30%を照合可能。
7. 宝具: 条件付き宝具威力50%を照合可能。
