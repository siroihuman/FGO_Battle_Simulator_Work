# 有限ターン状態の期限境界修正 受入記録

仕様書バージョン: 1.0.0
確認日: 2026-08-21
判定: 自動検査合格

## 結論

有限ターン状態の期限を、所持者側ターン終了、相手側ターン終了、手動の3種へ分離しました。聖母マリア「身籠る聖処女」のターゲット集中・対粛清防御は、付与した味方ターンの終了後も残り1ターンのまま敵行動へ入り、敵ターン終了で2状態とも失効します。

No.007「本多忠勝」の具体データ、他サーヴァント、敵、概念礼装、魔術礼装の追加は行っていません。

## 原因

従来の期限処理は、有限ターン状態を原則すべて`owner_turn_end`として登録し、終了側の前衛だけを減算していました。このため、味方行動中に付与した1ターンの防御系強化も味方ターン終了で失効し、敵行動まで残りませんでした。

## 修正した境界

| 種別 | 期限境界 |
|---|---|
| 攻撃系強化 | `owner_turn_end` |
| 防御系強化 | `opponent_turn_end` |
| その他強化 | `opponent_turn_end` |
| 通常の弱体 | `owner_turn_end` |
| 永続・手動状態 | `manual` |

- 終了時トリガーは従来どおり所持者側の終了時だけ発動し、期限減算とは分離します。
- 期限対象は終了処理開始時の双方前衛を固定し、終了側前衛、相手側前衛の順で処理します。
- 控え、終了処理途中で登場した個体、スナップショット後に追加された状態は同じ終了時に進めません。
- 味方・敵のどちらが所持者でも対称に動作します。

## 既存データへの接続

- 聖母マリア: 無敵、ターゲット集中、対粛清防御、毎ターンHP回復、宝具後最大HPアップ
- 千利休: 「一輪の花」の無敵
- 支配のフォーリナー: 「家のなかの絵」の毎ターンNP獲得・毎ターンスター獲得
- ルシフェラ: 宝具後の強化解除耐性
- アトラス院制服: 「オシリスの塵」の無敵

攻撃力、カード性能、クリティカル威力、宝具威力、スター集中度、OC段階増加等の攻撃系強化は、従来の所持者側終了を維持します。

`opponent_turn_end`は、形式4が既に保存している適用済み状態の`durationTick`欄へ保持します。直接再開は保存値を復元し、期限を再実行しません。検証リプレイは同じ操作から同じ状態・期限切れログ・乱数位置を照合します。
