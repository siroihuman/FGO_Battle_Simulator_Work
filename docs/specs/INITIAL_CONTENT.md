# 初期実装データ仕様

仕様書バージョン: 1.0.0

## 共通

- サーヴァントLvと宝具Lv以外のLvは最大。
- 強化前は実装しない。
- 保有スキルは上位3つ。
- 宝具は上位1つ。
- クラススキルはすべて。
- スキル・宝具は資料上の記述順で効果を登録する。
- データへ参照URLと確認日を保存する。

## 魔術礼装

計算・戦闘基盤の完成後に実装します。

### アトラス院制服

- 3スキル
- Lv最大
- 対象、CT、効果順を資料に合わせる

### ノーマルカルデア制服

「魔術礼装・カルデア」とは別物です。

- 応急支援
- 魔力強化
- オーダーチェンジ
- Lv最大

## 概念礼装

- 候補参照: https://appmedia.jp/fategrandorder/97937
- 計算・戦闘基盤を優先し、可能な場合に追加。

- 実装時は最大解放か未解放かを資料から確認し、データへ明記する。
