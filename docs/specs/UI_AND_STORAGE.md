# UI・保存仕様

仕様書バージョン: 1.0.0

## 設定画面

次の4タブへ分けます。

1. 味方編成
2. Wave・敵設定
3. 戦闘設定
4. 最終確認

入力中の内容は自動保存します。

## 味方編成

- 前衛3枠と控え3枠を表示。
- 前衛未設定では戦闘開始不可。
- 控え空欄可。
- 名前、クラス、レアリティで検索。
- 同じサーヴァントを選択肢から除外しない。
- サーヴァントLvと宝具Lvだけ編集可能。
- スキル等は最大固定と表示する。
- 複製、削除、上下・左右移動を用意する。

## 敵設定

- 最初に全Wave合計の敵参加数1～99を入力。
- 人数分の一覧行を生成。
- 通常表示は一覧、選択時に詳細を開く。
- 同時出現境界を明示。
- 複製、一括設定、個別上書きを用意。
- 通常攻撃、スキル、宝具は空欄可。
- 宝具未設定ならチャージ欄を無効化。
- 敵数削減時は削除確認し、取り消せるよう一時保持する。

## 戦闘画面

### 上部

- Wave
- 戦闘ターン
- Waveターン
- シード
- 中断保存
- 撤退

### 敵

- 枠番号
- 名称、クラス
- HP、ゲージ
- チャージ
- 状態
- 選択対象
- 控え数

6体時は3体ずつ2段表示する。

### 味方

- 前衛3騎
- HP、NP
- スキルとCT
- 状態
- 概念礼装
- 控え
- 魔術礼装
- スター

状態が多い場合は一部だけ表示し、詳細画面で全件を確認可能にする。

## カード操作

1. 対象選択
2. スキル・魔術礼装
3. 攻撃
4. カード3枚選択
5. チェイン確認
6. 実行

攻撃確定前はカードを選び直せます。使用済みスキルは取り消せません。

## ログ

- 初期表示は新しい順。
- 古い順へ切替可能。
- 通常表示は簡潔にする。
- 項目を展開すると計算式、Hit、乱数、状態理由を表示する。

## 保存

### 編成保存

味方、敵、Wave、戦闘設定を保存します。

### 中断保存

現在HP、NP、状態、CT、カードデッキ、乱数位置を保存します。

### リプレイ

開始設定、使用データ、シード、操作履歴から再現します。

保存データには仕様書バージョン、データ形式バージョン、乱数処理バージョンを含めます。

## スマートフォン

- 縦画面優先。
- 敵、味方、カードを縦配置。
- 攻撃・決定操作を下部固定。
- ログは開閉式。
- ホバー必須操作を作らない。
- ドラッグだけでなく移動ボタンを用意。
- パソコン版と計算・保存形式を共通化。

## 初期演出範囲

- HP・NP・チャージバー
- カード色
- アイコン
- ダメージ・回復数値
- 簡単な点滅・フェード

戦闘モーションと宝具演出は初期実装に含めません。画像がなくても動作可能にします。
