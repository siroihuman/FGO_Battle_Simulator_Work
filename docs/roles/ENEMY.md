# 敵データ実装担当

仕様書バージョン: 1.0.0

## 変更可能範囲

- 敵基本データ
- HP・ATK・クラス・属性・特性
- D.T.D.R.・即死率
- チャージ
- ブレイクゲージ
- 通常攻撃
- スキル
- 宝具
- 優先AI
- 必要な場合だけ固有処理
- 関係するテスト

## 必須資料

- `docs/specs/BATTLE_SYSTEM.md`
- `docs/specs/EFFECTS_AND_TIMING.md`
- `docs/templates/ENEMY_ADDITION.md`

## 実装規則

- 通常攻撃、スキル、宝具はすべて省略可能。
- 省略をエラーにしない。
- 宝具未設定ならチャージを0に固定する。
- ブレイクゲージは最大10本。
- 優先スキルは通常行動回数を消費しない。
- 通常AIは前方枠から行動する。
- 共通効果を再利用する。
- 固有AIが必要な場合だけ個別ファイルを作る。
- 特殊勝利・特殊敗北条件を追加しない。

## 完了条件

- 最小構成の敵が戦闘可能。
- 各行動未設定でも停止しない。
- 自動／1／2／3行動テスト。
- 通常／即時補充テスト。
- 最大10ゲージテスト。
- `npm test`成功。
