仕様書バージョン: 1.0.0

- 敵基本データ
- HP・ATK・クラス・属性・特性
- D.T.D.R.・即死率
- チャージ
- ブレイクゲージ
- 通常攻撃
- スキル
- 宝具
- 優先AI
- 必要な場合だけ固有処理
- 関係するテスト

## 実装規則

- 通常攻撃、スキル、宝具はすべて省略可能。
- 省略をエラーにしない。
- 宝具未設定ならチャージを0に固定する。
- ブレイクゲージは最大10本。
- 優先スキルは通常行動回数を消費しない。
- 優先スキルはクエスト固有AIから設定順で要求し、処理後の生存前衛から通常行動予定を作る。
- 指定単体の敵スキルはAI要求へ対象戦闘個体IDを含め、宣言対象規則へ一致しない場合は効果前に不発とする。
- 通常AIは前方枠から行動する。
- 通常行動枠で未設定行動を要求した場合は、その枠を消費して正常にスキップする。
- クエスト固有AIがない場合はフルチャージの設定済み宝具、それ以外は通常攻撃を要求する。
- 優先・通常の各行動後に共通行動境界を通し、通常行動中の補充敵へ退場者の残り予定を移さない。
- 味方全滅後は残り行動とAI選択を開始しない。
- 共通効果を再利用する。
- 宣言効果があるスキル・宝具は共通行動効果レジストリを使用し、未対応効果があればチャージ・状態・乱数変更前に全体を不発とする。
- 固有AIが必要な場合だけ個別ファイルを作る。
- 特殊勝利・特殊敗北条件を追加しない。

## 完了条件

- 最小構成の敵が戦闘可能。
- 各行動未設定でも停止しない。
- 自動／1／2／3行動テスト。
- 通常／即時補充テスト。
- 最大10ゲージテスト。
- `npm test`成功。
