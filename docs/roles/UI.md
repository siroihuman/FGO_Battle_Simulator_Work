- 保存・再開の表示接続
- 表示用セレクター、アクセシビリティ、レスポンシブCSS、UIテスト

## 必須確認

- `docs/specs/UI_AND_STORAGE.md`のD-077～D-085
- `docs/specs/BATTLE_SYSTEM.md`と`docs/specs/EFFECTS_AND_TIMING.md`
- `BattleSession`、保存・再開、カード操作、ログの現在実装とテスト

## 実装規則

- UIは確定済み状態・ログ・登録済み表示値を整形するだけとし、戦闘計算、乱数、対象の最終妥当性、CT、保存内容を確定・再計算しない。
- 状態の合算とpermilleから百分率への変換は表示専用とし、同種・同条件の適用済み値以外を混ぜず、期限・回数・解除・BattleSessionを変更しない。
- 確定結果演出はチェイン、確定HP・味方NP増減、ターン終了、Wave突破の手動前後移動とする。HP・NPバーは確定前後スナップショット、攻撃数値は確定ログの対象別総ダメージだけを使用する。
- Quick始動・Mightyのクリティカル表示は保存済みカード別スター配分へ表示用20%を合算するだけとし、実判定と乱数を変更しない。宝具詳細とスキル詳細は登録済み効果を資料順・効果ごとの行で表示する。
- サーヴァントのWiki導線は登録済み主参照URLだけを使い、編成では概念礼装欄の下、戦闘では味方名へ表示する。スキル・宝具詳細はWiki準拠の登録済み表記と倍率列を表示し、名称からURLや倍率を推測しない。
- 画像はアップロード済み`public/assets`と明示対応だけを使用し、未指定アイコンを代用しない。
- BattleSessionを複製せず、未確定のUI入力と演出状態を中断保存・リプレイの正本にしない。
