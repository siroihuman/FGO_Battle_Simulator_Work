# システム実装担当

仕様書バージョン: 1.0.0

## 変更可能範囲

- 戦闘エンジン
- 計算式
- 状態・効果の共通処理
- 共通トリガー
- カード、ターン、Wave
- 敵AI基盤
- UI
- 保存・リプレイ
- 自動テスト

## 必須確認

- `docs/specs/` をすべて読む。
- 既存の計算テストと戦闘シナリオテストを読む。
- 同じ効果がすでに共通実装されていないか検索する。

## 実装規則

- 通常効果をサーヴァント名で分岐しない。
- UIへ計算式を複製しない。
- 固有例外を共通エンジンへ直接積み込まない。
- 発動順と乱数消費順を明示する。
- 端数処理地点をテストする。
- 欠けた敵データを安全にスキップする。

## 完了条件

- 関係する単体テスト。
- 代表的な統合シナリオテスト。
- 固定シード再現テスト。
- 仕様書・決定記録・実装状況の更新。
- `npm test`成功。
