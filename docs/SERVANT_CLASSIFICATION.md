# サーヴァント実装カテゴリ一覧

仕様書バージョン: 1.0.0  
最終更新: 2026-08-21

## 目的

初期完成範囲外の具体サーヴァントを追加する前に確定した実装カテゴリを、この文書で保持する。次の担当者はチャット履歴や記憶から再判定せず、まずこの一覧を読む。

## 運用規則

- 対象は一覧ページの「データ」欄にあるサーヴァントとする。ページ名の先頭が「旧」の対象は実装しない。
- 取り消し線はフレーバーテキストページ未作成を示すだけであり、実装対象外の理由にしない。
- 派生霊基は個別に記録する。
- カテゴリは、既存の共通効果・共通トリガーで正確に実装できるか、最小の共通拡張が必要か、独自状態・固有システムが必要かを確認して決める。
- 確定済みのカテゴリ、理由、参照URLを変更する場合は、該当する個別データと既存実装を再確認し、決定記録へ理由を残す。
- この一覧にない候補は未分類である。No.順の実装候補として扱う前に、個別ページを確認して分類を追加する。未記録の候補を過去チャットや名称から推測してカテゴリ1へ入れない。
- スキルまたは宝具に強化前・強化後がある場合、初期実装では強化後だけを採用する。
