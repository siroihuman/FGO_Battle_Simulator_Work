## 既知の制約

- 未接続効果は unresolvedEffectStableIds または unsupported として明示し、近似実行しない。
- 敵宝具の段階別宣言値は必要な文脈データが追加されるまで、行動前に安全に不発とする。
- ターン終了トリガーによるスター獲得は、終了時解決器へ統合されるまで登録時に拒否する。
