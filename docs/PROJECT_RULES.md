# プロジェクト確定規則

仕様書バージョン: 1.0.0

この文書は新しいチャットが最初に把握するための短縮版です。詳細は `docs/specs/` を参照してください。

## 戦闘範囲

- 完全戦闘形式とする。
- 勝利は最終Waveの敵全滅、敗北は味方全滅のみ。
- 特殊勝利条件と特殊敗北条件は実装しない。
- 同時全滅は敗北。
- 撤退は勝敗と別に記録する。
- 最大3Wave。

## 戦闘進行

- 戦闘状態は味方行動、味方ターン終了、敵行動、敵ターン終了、終了済みに分ける。
- 勝敗・Wave判定は味方または敵のターン終了処理がすべて完了した後だけ行う。
- 初回の味方行動を戦闘ターン1・Waveターン1とする。
- 次の味方行動を開始するたび戦闘ターンを1増やし、同じWaveならWaveターンも1増やす。
- 次Waveの最初の味方行動では戦闘ターンを1増やし、Waveターンを1へ戻す。
- 前衛・控えの生存敵に加え、ブレイク保留・復活保留・追加出現予定のいずれかが残る間はWave終了にしない。

## 味方編成

- 前衛3騎は必須。
- 控えは0～3騎で空き枠を許可。
- 同一サーヴァントの重複編成に制限を設けない。
- サポート枠を区別しない。
- 戦闘不能者は控え末尾へ移動し、控え先頭の生存者が同じ前衛枠へ登場する。
- 複数同時戦闘不能は前衛の枠順で処理する。
- 戦闘不能の控えは編成順を維持したまま飛ばし、生存する控えがいなければ前衛を空き枠にする。
- オーダーチェンジは指定した前衛と控えを直接交換し、HP・NP・状態・CTを維持する。
- 控え中は状態の残りターン、毎ターン効果、スキルCTを停止する。

## 敵編成

- 敵参加数は全Wave合計で1～99体。
- 同時出現上限は3体または6体から選択する。
- 敵を同一データから複数配置できる。
- ブレイクゲージは最大10本。
- 戦闘不能敵は1行動完了後の安全な境界で消滅し、前方の空き枠から控え先頭の生存敵を入れる。
- 通常補充では敵ターン終了時だけ空き枠へ補充する。
- 即時補充では戦闘不能処理後の次行動開始前と敵ターン終了時に補充する。
- 戦闘不能の控えは飛ばして消滅させ、生存する控えの編成順を維持する。
- 敵に控えが残っている限りWave全滅とは扱わない。

## 敵行動

- 通常の総行動回数は最大3回。
- 個別の最大行動回数は自動／1／2／3から設定する。
- 自動設定は、前衛1体なら3回、2体なら各2回、3体以上なら各1回。
- 行動順は原則前方枠から。
- 通常行動全体の基本予算は3回とし、前方から巡回して個別上限まで割り当てる。
- 優先スキルは通常行動より先に発動し、通常行動回数を消費しない。
- 優先スキルはクエスト固有AIの設定順で処理し、その処理と即時補充が終わった時点の生存前衛から通常行動予定を作る。
- 行動回数増加状態による追加分は、その状態を持つ敵だけが基本3回を超えて行動する。
- 通常攻撃、スキル、宝具が未設定でもエラーにしない。
- 通常行動枠で要求された未設定行動は、その1枠を消費して正常にスキップする。未設定の優先スキルは通常行動枠を消費しない。
- 宝具未設定の敵はチャージを常に0とする。
- 宝具は実行直前に設定・生存・前衛・行動可否・チャージ最大を再確認し、成立時はチャージを0に戻してから効果を解決する。

## カード

- 前衛3騎なら15枚、2騎なら10枚、1騎なら5枚でデッキを作る。
- 各サーヴァント固有の5枚を戦闘個体IDとカード番号で区別する。
- 毎ターン5枚配布する。
- 未配布から重複なしで5枚をカード用乱数列により選ぶ。
- 周期の残り0枚後は、次回配布直前の生存前衛から再構築する。
- 通常カード3枚を選択する。
- 選択入力は現在配布中の通常カードと、生存前衛の使用可能な宝具カードから重複なしで3枚ちょうどとする。
- 各色チェイン、Mighty、Brave、Extra Attack、宝具チェイン、OCを実装する。
- 同色チェインとBraveチェインは宝具カードも1枚として数え、Braveは元データIDではなく戦闘個体IDが3枚とも同じ場合に成立する。
- Quickチェインは20スター、Artsチェインは各参加個体へNP20%、Busterチェインは通常カードだけにATKの20%分を加える。
- Mightyチェインはカード順を問わずQuick／Arts／Busterの1stボーナスをすべて通常カードへ適用する。
- Extra Attackのカード値は各100%、混色・Mighty Braveは2倍、同色Braveは3.5倍とし、クリティカルは発生しない。
- 行動不能者の通常カードが1枚でも含まれればチェインエラーとして全チェインを不成立にし、1枚目の所有者も行動不能なら1stボーナスも不成立とする。
- 宝具チェインは連続した宝具だけを数え、連続2枚目へOC1段階、3枚目へOC2段階を加える。ゲージとOC段階増加を合わせた上限は5段階とする。
- 宝具はカード位置補正と1stボーナスを受けない。
- 宝具使用時にNPを0へ戻す。
- 行動不能者のカードも選択可能だが実行時に不発とする。
- 宝具選択時と実行直前の両方でNP・封印・生存状態を確認する。
- 宝具は前衛・行動可否も同じ2地点で確認し、実行直前に不成立ならNPを消費せず不発とする。
- 通常カードも実行直前に所持者の前衛・生存・行動可否を確認し、不成立なら正常な不発として扱う。
- 味方退場時は自動交代後の生存前衛から次回配布用デッキをリセットし、現在の5枚は維持する。
- オーダーチェンジとWave移行ではデッキをリセットしない。

## 対象と攻撃継続

- 攻撃開始時の対象を基準とする。
- 対象が消滅した場合は、原則として元対象の後方枠を次の対象とする。
- 空き枠を飛ばし、後方にいなければ前方へ回り込む。
- 即時補充された敵を無条件で優先しない。
- 1枚のカードの全Hitを終えてから死亡、消滅、補充、次カードを処理する。
- 全体通常攻撃も1枚全体を完了してから次へ進む。
- 対象開始時の戦闘個体IDと前衛枠を保持し、消滅後は元枠の後方、前方への回り込み、元枠の順に再選択する。
- 行動完了境界では死亡・自動交代・敵補充だけを接続し、ブレイク・Wave・勝敗・ターン遷移を先行判定しない。
- 選択した3枚とBraveチェイン時のExtra Attackを順番に進め、各1行動の実効果または不発後に共通行動境界と対象再選択を必ず処理する。
- 敵対象が尽きた場合は残りカードを開始せず、宝具NPも消費せず、味方ターン終了へ進む。
- 先行カード後の状態変化は後続カードの実行可否へ反映するが、カード確定時のチェイン成立情報は変更しない。
- 次Waveへ残りカードを持ち越さない。

## ブレイク

- 現在ゲージを含め、敵1体あたりのHPゲージは最大10本。
- 中間ゲージが0になった敵はブレイク保留状態とする。
- 次ゲージが残る敵のHP0は自動でブレイク保留となり、ガッツを消費しない。
- ブレイクは味方ターン終了時に発生する。
- 同じ敵が1味方ターン中に破壊できる中間ゲージは最大1本。
- ブレイク保留中も残りカードはオーバーゲージとしてHitする。
- ブレイク保留は前方の敵から処理し、明示的に対象となった控えの保留はその後に編成順で処理する。
- 次ゲージへ移る際は継続中の最大HP変更状態を再適用して全快し、その他の状態・CT・特性を維持する。
- ブレイクごとに`on_break`発動イベントを生成する。
- 最終ゲージ0は通常の戦闘不能処理を行う。
- スリップダメージはブレイクできず、対象をHP1で残す。

## NP・スター・乱数

- NP内部値は0.01%単位。
- 宝具Lv.1の上限は100%、Lv.2～4は200%、Lv.5は300%。
- 正のNP加算後に99.00～99.99%なら100%へ補正する。
- 直接NP増加、Artsチェイン、毎ターンNP増加はNP獲得量アップ・ダウンの影響を受けない。
- スター所持上限は99個。
- 最初の50個をカードへ配分し、51～99個目はスター消費効果に使用できる。
- 使用されなかったスターは次の次のターンへ持ち越さない。
- ランダムモードと固定シードモードを実装する。
- 同じシード、設定、操作なら完全に同じ結果とする。

## ターン終了効果

- 味方の毎ターン回復・毒等は味方ターン終了時に処理する。
- 敵の毎ターン回復・毒等は敵ターン終了時に処理する。
- 控え中は発動も残りターン消費も行わない。
- 発動順は前衛の枠順、優先度、登録順とする。
- 1ターン状態を含め、終了時効果を実行してから残りターンを減らす。
- 終了処理開始時に発動候補と最終登録順を固定し、処理中に付与された状態は次回まで発動させず残りターンも減らさない。
- 終了処理開始時に残りターン更新対象の前衛個体も固定し、処理途中で控えから登場した個体はその終了時点では減らさない。
- 先行効果で解除された状態や、戦闘不能・前衛外になった所持者の後続候補は発動しない。
- 効果の対象範囲は状態所持者を基準に解決し、与HP回復量等の付与者側補正には元の付与者を使用する。
- 対象不在は正常な不発として扱い、乱数を消費しない。
- 通常の毎ターンHP回復とスリップダメージだけを同時精算対象として明示し、その他の終了時効果は発動順で即時実行する。
- 同一対象の通常毎ターンHP回復は基礎量をまとめ、元の付与者ごとの与HP回復量補正と対象の被HP回復量補正を適用して1回の回復として扱う。
- 回数制の与HP回復量補正は同じ付与者につき1回、被HP回復量補正と回復不能は対象につき1回だけ消費する。
- 毎ターン回復とスリップは合計後に同時反映し、最後にHP1～最大HPへ丸める。満HPでも回復分は同時発生したスリップを相殺できる。
- スリップ精算ではブレイク・ガッツ・戦闘不能を発生させず、HP1で停止する。
- 味方ターン終了はブレイク・`on_break`効果・味方毎ターン効果・敵消滅／即時補充・味方自動交代・期限・前衛／魔術礼装CT・勝敗判定の順で共通処理する。
- 敵ターン終了は敵毎ターン効果・味方自動交代・敵消滅・期限・生存前衛CT・通常補充・勝敗判定の順で共通処理する。
- 勝敗とWave移行は、各ターン終了コーディネーターの全処理後だけ判定する。

## 防御・ガッツ・即死

- 防御状態は対粛正防御、無敵、回避の順に処理する。
- 必中は回避だけ、無敵貫通は無敵と回避を貫通し、対粛正防御は貫通しない。
- 貫通された回数制防御も1回消費するが、同じ攻撃単位の下位防御は続けて消費しない。
- 防御無視は正の防御力アップだけを無視し、防御力ダウン、特殊耐性、ダメージカットには影響しない。
- 中間ブレイクではガッツを発動せず、最終HP0でガッツを判定する。
- ガッツ発動時は死亡時効果を発動しない。固定値ガッツは回復量補正を受けず、割合ガッツだけ指定補正を受ける。
- 即死は効果率、対象の基礎即死率、付与者の成功率、対象の耐性を計算してから即死無効を確認する。
- 即死無効は即死確率が成功し、実際に防いだ場合だけ古いものから1回消費する。
- 攻撃前即死が成立した場合は後続Hitを停止し、最終ゲージならガッツ、中間ゲージならブレイク保留へ進める。

## HP回復・最大HP・吸収

- 与HP回復量補正は付与者側、被HP回復量補正は対象側でそれぞれ加算し、2区分を乗算する。
- 回復不能は通常HP回復とHP吸収による回復を止めるが、固定値ガッツと最大HP上昇は止めない。
- 最大HPは基礎値と一時状態適用後の値を分け、すべての有効な最大HP変更状態から再計算する。
- 最大HP上昇の付与時は、実際に増えた最大HPと同量だけ現在HPも増やす。
- 最大HP変更の解除・期限切れで最大HPが戻っても現在HPは増やさず、新しい最大HPを超える場合だけ丸める。
- 最大HPは1未満にしない。
- HP吸収は対象ごとの実減少量を合計し、全対象の減少後に吸収元へ1回だけ通常HP回復を行う。
- HP0可能なHP減少と吸収は、中間ブレイク・ガッツ・最終死亡の共通確定処理を使用する。

## 特性・状態の重要例外

- Roma特性付与だけを弱体として扱う。
- Roma以外の特性付与は強化でも弱体でもない。
- 弱体付与は付与者の弱体成功率と対象の弱体耐性、強化付与は付与者の強化成功率と対象の被強化成功率を個別に計算する。
- 1つのスキル・宝具・トリガーに複数状態があっても、回数制弱体無効・強化無効は同じ付与行動に対して1回だけ消費する。
- 1個解除は最新の対象を選んでから解除判定し、全解除は開始時点の候補を個別に判定する。
- 恐怖・混乱は確率発動に成功した時点で回数を消費する。
- 子効果が対魔力等で防がれても回数を消費する。
- 確率発動自体に失敗した場合は回数を消費しない。
- 即死デメリットはガッツ無視フラグを持てる。
- ガッツ無視ならガッツがあっても戦闘不能にする。

## Lvと初期データ

- サーヴァントLvと宝具Lv以外は最大Lvで固定する。
- 強化前データは実装しない。
- 宝具は上位1つ、保有スキルは上位3つ、クラススキルはすべて実装する。
- 初期サーヴァントは光のコヤンスカヤとルシフェラ。
- アトラス院制服とノーマルカルデア制服は基盤完成後に実装する。
- 指定された概念礼装は可能なら追加する。
