# FGO Battle Simulator Work

Fate/Grand Order形式の完全戦闘シミュレーターを、計算精度と再現性を優先して新規構築するプロジェクトです。

現在は初期サーヴァント実装へ入る効果データ統合段階です。サーヴァント定義に加え、スキル・クラススキル・宝具の固定値、宝具Lv別値、OC別値、対象範囲を型付きデータとして既存のHP・NP・状態処理へ渡せます。クラススキルの戦闘開始時初期化と、味方スキルのCT設定、効果、戦闘不能、自動交代を一つの安全な処理として実行し、未対応効果は状態・乱数変更前に拒否します。

## 重要

- リポジトリ内の文書とテストを、チャット履歴より優先する「唯一の正本」とします。
- 作業を始める前に [AGENTS.md](AGENTS.md) を読みます。
- 新しいChatGPTチャットへ移る場合は [新しいチャットの開始方法](docs/NEW_CHAT_GUIDE.md) を使用します。
- 現在の進捗は [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md) で確認します。
- 仕様書の案内は [docs/INDEX.md](docs/INDEX.md) にまとめます。

## 初期完成版の範囲

- 味方前衛3騎、控え0～3騎
- 最大3Wave
- 全Wave合計で敵1～99体、同時出現3体または6体
- 通常補充と即時補充
- 最大10ゲージ
- コマンドカード、各種チェイン、宝具、NP、スター
- 味方・敵双方の行動
- ランダムモードと固定シードモード
- 全滅戦のみ
- 初期サーヴァント2騎
- パソコン・スマートフォン対応

特殊勝利条件、特殊敗北条件、コンティニュー、戦闘アニメーションは初期実装に含めません。

## 基盤検査

Node.js 20以上で次を実行します。

```bash
npm test
```

確定仕様の重要値と必須文書に加え、固定小数点、用途別乱数、乱数監査、個体別攻撃データ、カード・敵攻撃入力、対象別ダメージ、複数対象Hit、NP、スターの発生・寿命・消費・手札配分、クリティカル、状態、防御、ブレイク・ガッツ・死亡、攻撃トリガー列、ターン終了効果、味方カード列、敵優先・通常行動列、安全な行動境界、1戦闘ターン統合、Wave・勝敗を含む時系列ログ、宣言的サーヴァントデータ、共通効果データ、クラススキル初期化、味方スキル使用の回帰テストを実行します。

型検査と公開用ビルドは次で確認できます。

```bash
npm run typecheck
npm run build
```
