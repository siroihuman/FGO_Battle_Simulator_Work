# FGO Battle Simulator Work

Fate/Grand Order形式の完全戦闘シミュレーターを、計算精度と再現性を優先して新規構築するプロジェクトです。

現在は状態・効果基盤の実装段階です。計算・乱数に加え、対象指定、付与・解除、防御・貫通、ガッツ・即死、最大HP変更・HP吸収、味方・敵別のターン終了効果を自動テストで固定し、チャットを変更しても記述や認識が揺れない開発環境で進めます。

## 重要

- リポジトリ内の文書とテストを、チャット履歴より優先する「唯一の正本」とします。
- 作業を始める前に [AGENTS.md](AGENTS.md) を読みます。
- 新しいChatGPTチャットへ移る場合は [新しいチャットの開始方法](docs/NEW_CHAT_GUIDE.md) を使用します。
- 現在の進捗は [IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md) で確認します。
- 仕様書の案内は [docs/INDEX.md](docs/INDEX.md) にまとめます。

## 初期完成版の範囲

- 味方前衛3騎、控え0～3騎
- 最大3Wave
- 敵1～99体、同時出現3体または6体
- 通常補充と即時補充
- 最大10ゲージ
- コマンドカード、各種チェイン、宝具、NP、スター
- 味方・敵双方の行動
- ランダムモードと固定シードモード
- 全滅戦のみ
- 初期サーヴァント2騎
- パソコン・スマートフォン対応

特殊勝利条件、特殊敗北条件、コンティニュー、戦闘アニメーションは初期実装に含めません。

## 基盤検査

Node.js 20以上で次を実行します。

```bash
npm test
```

確定仕様の重要値と必須文書に加え、固定小数点、用途別乱数、Hit分配、NP、スター、対象、状態、防御、死亡処理、ターン終了効果の回帰テストを実行します。

型検査と公開用ビルドは次で確認できます。

```bash
npm run typecheck
npm run build
```
